# UCI Wine Statistical & Visual Analysis

Reproducible exploratory, descriptive, and inferential statistical workflow on the UCI Wine dataset ($N = 178$).

## Key Findings
- **ANOVA (Flavanoids):** $F(2, 175) = 233.93, p < 0.0001$
- **Welch's t-test (Alcohol, Cultivar 0 vs 1):** $t = 16.71, p < 0.0001$
- **Pearson Correlation (Alcohol vs Proline):** $r = 0.6437, p < 0.0001$
